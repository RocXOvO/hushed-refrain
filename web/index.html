USER ID GUIDE

如何获取用户 UID

UID 是网易云音乐用户主页链接里的纯数字编号，不是昵称。

  1. 打开网易云音乐客户端或网页版。
  2. 进入要查找的用户主页，选择“分享”并复制主页链接。
  3. 找到链接中 id= 后面的数字，把它粘贴到 UID 输入框。
示例主页链接music.163.com/#/user/home?id=123456789

上面示例中的 UID 是 123456789。手机分享出的短链接也可以先在浏览器打开，再从跳转后的用户主页地址中读取。

IDENTITY PARSING EXPERIMENT

EncryptUin 解析实验

先判断输入类型。裸 EncryptUin 和直接携带 EncryptUin 的官方主页链接只在本地提取、离线解码；十进制 QQ / 内部 ID 候选需要你明确点击后联网获取 canonical EncryptUin。这些低频普通查询固定使用本机直连，不读取代理池；代理池只服务正式高并发扫描。32 位新式 ID、任意外域链接和其他不透明 Token 都会拒绝。

解析结果-

按你的显示设置，解析成功后会直接显示完整 QQ 号候选；微信登录身份只标记为“微信用户”。复制仍只在你明确点击后写入剪贴板。点击在线验证会把 canonical EncryptUin 与解码候选标识通过本机直连发送到 QQ 官方公开资料接口。

输入只会在你点击后处理一次；不会批量导入、枚举或反查。
